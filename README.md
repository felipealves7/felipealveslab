# airport-runs

Saved runs of the airport data contract, written by `.github/workflows/airport-contract.yml`
on `main`. Every run is kept, passed or failed, newest last; the latest 52 stay.
`/lab/airport-data-contract` reads `results.json` from here.

Source: OurAirports open data, https://ourairports.com/data/ (Public Domain, no guarantee of
accuracy). Code and method: `pipelines/airport-contract/` and `data/airport-contract/README.md`
on `main`.
