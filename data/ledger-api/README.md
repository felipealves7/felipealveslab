# Ask the Ledger (live): data

- **Source:** synthetic. Generated by `pipelines/ledger-api/dataset.mjs` with seed 2028: 8 cost centres, 8 accounts, 20 invented vendors, 420 invoices dated 2026-01-01 to 2026-09-30, amounts in whole AED. No real company, employer or third-party data.
- **Licence:** none needed. Generated by this repository's code (MIT).
- **Date generated:** 2026-10-29.
- **Synthetic:** yes.
- **Files:** `scorecard.json` (12 fixed questions, their reference queries and expected answers, and the verdict for any generated query supplied in `generated.json`) and `recorded.json` (the example session). Identical copies sit in `public/data/ledger-api/` so the browser can load them. The D1 files `schema.sql` and `seed.sql` are in `worker/ledger-api/sql/`.
- **Rebuild all:** `node pipelines/ledger-api/build.mjs`. A test fails if the saved files drift from a fresh build.
- **`generated.json`:** does not exist yet. When it does, it holds `{"<question id>": "<SQL the model wrote>"}` and the scorecard counts it. Until then every question shows "not run" and there is no accuracy figure.
