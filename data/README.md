# data/

Small datasets and pipeline outputs. Every dataset lives in its own folder with a `README.md` that states:

- source and URL, and the licence page you opened
- retrieval date and update cadence
- whether it is synthetic, and how it was generated
- columns and units

No personal data, except Felipe's own self-tracking data on Human Variable labs, published as aggregates only. No employer data.

Folders: `airport-contract/`, `ask-the-ledger/`, `attention/`, `aviation-reliability/`, `ccee-pld/`, `ccee-pld-horario/`, `ledger-api/`, `ledger-eval/`.
